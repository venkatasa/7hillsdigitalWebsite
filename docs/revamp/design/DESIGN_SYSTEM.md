# 7Hills Digital — Visual Design System (v2)

**Prepared:** 30/10/2026 · **Status:** For visual approval, alongside the staging prototype.
Covers deliverables **1** (design system), **6** (interaction and animation spec) and
**7** (reusable components). Page compositions are in `PAGE_COMPOSITIONS.md`.

---

## 1. The idea: *seven hills, mapped*

Most IT sites reach for the same props: blue gradients, glowing orbs, isometric
servers. 7Hills gets one signature motif that comes from its own name: **a
topographic contour map of seven hills**.

- Contour lines are how engineers and surveyors describe terrain: precise,
  layered, measured. That's the tone: *we map your business before we build on it.*
- The map is **computed, not drawn**: iso-lines of seven peaks, generated by
  `resources/art/contours.py` (in the same spirit as `brand:banner`). It's
  original, reproducible and 11 KB gzipped.
- It is rendered as a **CSS mask**, so its colour is always `var(--brand-mint)` at
  low opacity. No hex value is baked into the artwork.
- It appears in **three places only**: the hero, the services showcase, and the
  closing band. Overused, it would become wallpaper.

Supporting the motif: **annotation**. Screenshots carry small leader-line captions
("Back office · staging install, fictional data"), like the call-outs on an
engineering drawing. Honest labelling becomes part of the look rather than
small print.

## 2. Colour

Only the official palette (`config/brand.php`). Depth comes from **tints and opacity
of those same tokens** via `color-mix()`; no new hues.

| Role | Token / derivation | Use |
|---|---|---|
| Night surface | `brand-dark` #122118 | Hero, showcase, trust band |
| Forest surface | `brand` #1A2E22 | Raised panels on night, dark cards |
| Raised on dark | `color-mix(brand 88%, white)` | Tab rail hover, frame chrome |
| Line on dark | `white / 8%` · strong `white / 14%` | Borders, dividers |
| Paper | white | Default light band |
| Mist | `brand-light` #F8FAF9 | Alternating light band |
| Line on light | `hairline` #E2E8E5 | Borders |
| Accent on light | `accent` #417956 | Links, `btn-accent`, eyebrows |
| Accent on dark | `mint` #5EB87E | `btn-mint`, eyebrows, contour lines, focus ring on dark |
| Ink | `ink` #111111 / `secondary` / `muted` | Text on light (≥ 4.5:1) |

**Rules** (unchanged from CLAUDE.md, now enforced by the components):
`accent` never on dark, `mint` never as text on white. A component takes a
`tone="dark|light"` prop and picks the right accent itself, so the rule can't be
broken by hand.

**Accent budget:** one mint or emerald focal point per viewport. Most of the page
is neutral; the colour means "act here".

## 3. Typography

Montserrat (display) + Plus Jakarta Sans (body), self-hosted as today.

| Style | Font / weight | Size (fluid) | Tracking / leading | Use |
|---|---|---|---|---|
| `t-hero` | Montserrat 800 | `clamp(2.6rem, 1.4rem + 4.4vw, 5.25rem)` | −0.035em / 1.02 | Home H1 only |
| `t-display` | Montserrat 800 | `clamp(2.2rem, 1.4rem + 2.8vw, 3.75rem)` | −0.03em / 1.05 | Page H1 |
| `t-title` | Montserrat 700 | `clamp(1.85rem, 1.3rem + 1.6vw, 2.75rem)` | −0.025em / 1.1 | Section H2 |
| `t-subtitle` | Montserrat 700 | 1.25–1.5rem | −0.015em / 1.2 | Card and panel titles |
| `t-lede` | Jakarta 400 | 1.125–1.3rem | 0 / 1.6 | Intros |
| body | Jakarta 400 | 1rem | 0 / 1.65 | Copy |
| `t-label` | Montserrat 700 caps | 0.72rem | 0.16em | Eyebrows, captions |
| `t-figure` | Montserrat 800, `tabular-nums` | 2.5–4.5rem | −0.04em | Stats, prices |

- Headlines use `text-wrap: balance`; paragraphs use `text-wrap: pretty`.
- Measure: body ≤ 64ch; ledes ≤ 56ch.
- **No new typeface.** No monospace font is added; the "technical" feel comes from
  tabular figures, index counters and annotation labels.

## 4. Space, grid, shape and depth

- **Grid:** 12 columns at `lg` (≥ 1024px), 8 at `md`, 4 on mobile. Containers:
  `container-page` (72rem, text) and the new `container-wide` (80rem, compositions).
  Side padding is 20px on mobile and 32px from `sm`.
- **Vertical rhythm:** `section` (96–128px desktop), `section-tight` (64–80px). One knob.
- **Radius scale:** 10px (buttons, chips) · 16px (cards) · 22px (panels, device
  frames) · 999px (pills).
- **Elevation** (shadows tinted with `brand-dark`, never grey):
  - `e1`: hairline + `0 1px 2px` (resting card)
  - `e2`: `0 8px 24px -12px` (hover)
  - `e3`: `0 30px 60px -20px` + `0 12px 24px -12px` (device frames)
- **Borders:** 1px everywhere. Featured surfaces get a **1px gradient edge**
  (mint → transparent) drawn with a masked pseudo-element. It's used on two or
  three elements per page, never as decoration on every card.
- **Section transitions:** the dark hero ends in a soft 1px mint-tinted horizon
  line; dark-to-light changes always pair with an element that *crosses* the
  boundary (the showcase panel's top edge overlaps the band above it), so bands
  read as composed, not stacked.

## 5. Imagery

| Allowed | Source | Label shown |
|---|---|---|
| Demo tenant pages | Staging, captured by script | "Demo tenant · fictional business" |
| 7Hills back office | Staging install, **fictional data only** | "Back office · staging install, fictional data" |
| Client public sites | Only with the client's written permission for the **exact image**, with no identifiable people unless they consented | "Client site · live" |
| Diagrams (flows, hubs, architecture) | Hand-built SVG | "Illustration" |
| Stock photography, AI-generated scenes, fabricated dashboards | — | **Never** |

Every image under `public/images/product/` has an entry in
`public/images/product/manifest.json` (source, captured date, label, alt text).
A test fails if an image lacks an entry, or if its source is a client back office.

Screens sit in **device frames** (`ui.frame-browser`, `ui.frame-phone`) at 1×
and 2× WebP, with explicit `width`/`height` and `loading="lazy"` below the fold.

## 6. Iconography

A single **1.5px-stroke, 24px-grid** icon set, drawn in-house as inline SVG
(`<x-ui.icon name="…">`), with rounded caps and joins. It's used sparingly: in
navigation, the spectrum stations and the trust ledger, **not** as a decoration on
every card. The existing `<x-package-icon>` stays for packages, for consistency
with the current pages.

## 7. Interaction and animation specification (deliverable 6)

### 7.1 Motion tokens
| Token | Value | Use |
|---|---|---|
| `--dur-fast` | 140ms | Hover, press, focus |
| `--dur-base` | 220ms | Menus, tabs, toggles |
| `--dur-slow` | 640ms | Scroll reveals (once) |
| `--ease-out` | `cubic-bezier(.2,.7,.2,1)` | Everything entering |
| `--ease-in-out` | `cubic-bezier(.65,0,.35,1)` | Panels switching |

### 7.2 Behaviours
| Element | Behaviour | Reduced motion |
|---|---|---|
| Buttons | 1px lift + `e2` shadow on hover; arrow glyph nudges 3px; press returns to 0; **visible 2px focus ring** (accent on light, mint on dark) with offset | Colour change only |
| Cards / tiles | Border warms to `accent/35`; a soft **spotlight** follows the pointer (CSS custom properties set on `pointermove`, fine pointers only) | No spotlight |
| Scroll reveal | `data-reveal`: 12px rise + fade, **once**, stagger 60ms within a group. Content is visible without JS | Off: always visible |
| Hero depth | Device frames shift ±6px with the pointer (desktop, fine pointer). No autoplay | Off |
| Header | Transparent over the hero with the inverse logo; past the hero it becomes paper with `backdrop-blur` and the standard logo (220ms cross-fade) | Instant swap |
| Mega-menus | Open on click (and on hover with a 120ms intent delay); fade + 4px drop; `Esc` closes and returns focus; `aria-expanded` set | Fade only |
| Mobile nav | Full-height sheet; body scroll locked; focus moves to the first link; `Esc` and the close button close it; groups are accordions (`x-collapse`) | No slide |
| Tabs | WAI-ARIA tabs: arrow keys, `Home`/`End`, roving `tabindex`, panel cross-fade 220ms. **Without JS, every panel renders in sequence** | No fade |
| Segmented control (industries, process) | Sliding indicator under the active option (transform only) | Instant |
| Forms | Submit button → spinner + "Sending…", disabled to stop double posts; inline errors under fields with `aria-describedby` | Same |
| Images | Aspect-ratio box with a `mist`/`forest` placeholder, so nothing shifts | Same |

**Never:** autoplay carousels, looping background animation, scroll-jacking,
parallax on scroll, cursor followers, sound, or animation that delays content.

### 7.3 Loading and empty states
- **No published packages** (guarded by `EmptyStateTest`): the platforms section
  shows "Our platforms are being updated — tell us what you need" with the
  consultation CTA, and the hero price line is hidden rather than showing R0.
- **Offering hidden by availability:** it isn't rendered at all; tab counts adjust.
- **Image missing:** the frame shows the placeholder surface and its caption; the
  layout holds.
- **Slow network:** fonts use `font-display: swap`; hero text is the LCP element,
  and the images below it lazy-load.

### 7.4 JavaScript budget
Alpine.js (already loaded) plus about 60 lines of vanilla JS for reveal, header state
and pointer depth. **No new libraries.** Target ≤ 25 KB gzipped total (today 19.5 KB).
